# 公用知識庫索引

本目錄為**跨專案共用**的知識庫，儲存可重用的注意事項，供所有專案的任務參考。

> 📍 預設位置 `$HOME/.knowledge-skill/knowledge/`，可用環境變數 `KNOWLEDGE_BASE_DIR` 覆寫。

## 使用方式

索引分兩層，**平時只需讀這一份**：

1. **任務開始前**：掃下方「分類目錄」的知識標題，判斷手上的任務屬於哪個分類
2. **有命中才往下讀**：開啟該分類的子索引 `{分類}/index.md`，裡面才有完整的「觸發時機」與「摘要」
3. **確定相關才讀知識檔**：依子索引的相對路徑開啟該知識檔
4. **任務完成後**：如有可跨專案重用的注意事項，依分類目錄新增知識檔，再由 `kb-reindex.sh` 重建兩層索引（不手動編輯）

知識檔依分類歸檔（頂層 `ui` / `ux` / `dev` / `ops` / `data` / `else`，第二層依語言或框架，如 `dev/php-laravel/`）。已停用（被取代）的決策另記於 [deprecated/index.md](deprecated/index.md)。

**何時產生知識檔案：**
- 使用者明確指定要記憶的原則、習慣或規則
- 跨專案可重用的工作方法或解決方案
- 透過互動修改後發現、未來仍適用的重要事項

**不需要產生：** 一般程式設計知識、框架標準用法、官方文件已說明的內容、僅對單一專案成立的細節
